Prep Home Learning Tablet App V2

Best tablet experience:
1. Host this folder on an HTTPS website.
2. Open the URL on the tablet.
3. iPad: Safari > Share > Add to Home Screen.
4. Android: Chrome > menu > Add to Home screen / Install app.

The website itself can also be tested by opening index.html on a computer.

Included:
- Week dashboard
- Today screen
- Saturday quiz with automatic score
- Progress saved in the browser
- Word worksheet links
- Tablet responsive layout
- Basic PWA files for Add to Home Screen when hosted over HTTPS

Current content baseline: Victorian Prep/Foundation, Term 3 Week 5.
